# تحديث واجهة تطبيق هارون بلاست (OTA)

التطبيق (أندرويد) يفتح هذه الصفحة عند كل إقلاع ويقارن `version` بالنسخة المحفوظة عند الزبون.

**لتحديث واجهة التطبيق لاحقًا:**
1. استخرج الحزمة الجديدة من الـAPK بعد البناء:
   `unzip -p app-release.apk assets/index.android.bundle > bundle.js`
2. ارفع `bundle.js` (استبدل الملف).
3. ارفع رقمًا أكبر في `version.json` (مثلاً 2 ثم 3 …).

عند فتح التطبيق سيكتشف الزبون النسخة الأحدث وينزّلها تلقائيًا خلال ثوانٍ — بدون تحميل APK جديد.
